# Weather App

A simple weather application that fetches real-time weather data using the OpenWeatherMap API.

## Features

- **Real-time Weather:** Get the current weather updates for any city.
- **Detailed Information:** Displays temperature, humidity, and wind speed.
- **Visual Indicators:** Shows weather icons representing the current condition (Clouds, Rain, Clear, Mist, Drizzle).
- **Error Handling:** Notifies users when an invalid city name is entered.

## Technologies Used

- **HTML:** Structure of the web page.
- **CSS:** Styling and layout of the application.
- **JavaScript:** Logic to fetch data from the API and update the DOM.
- **OpenWeatherMap API:** Source of the weather data.

## How to use

1. Open the project folder.
2. Double-click on `index.html` to open it in your web browser.
3. Enter a city name in the search bar.
4. Click the search icon to view the weather details.

## Project Structure

- `index.html`: The main HTML file containing the structure and JavaScript logic.
- `style.css`: The CSS file for styling the application.
- `images/`: Folder containing weather icons and assets.

## Note

This application uses a free API key from OpenWeatherMap. For production use or higher rate limits, you should generate your own API key and replace it in the `script` section of `index.html`.
